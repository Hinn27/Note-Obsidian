## Android Dev:
1. Học Kotlin với JetBrains và [roadmap.sh](http://roadmap.sh)
	1. Làm quen Kotlin:
        - Học syntax: null safety, data class, extension function, lambda, higher‑order function
        - Làm vài bài tập nhỏ: model đơn giản, xử lý list, map, coroutine cơ bản
    2. Android cơ bản với Kotlin:
        - Activity, Fragment, vòng đời, Intent, RecyclerView, ViewBinding/DataBinding
        - Gọi API (Retrofit/OkHttp), lưu local (Room)
    3. Jetpack & kiến trúc:
        - MVVM + ViewModel + LiveData/Flow, Repository pattern
        - Navigation Component, WorkManager, Hilt/Dagger cho DI
    4. Jetpack Compose:
        - Compose essentials trên trang Android Developers (composable function, state, layout)
        - Dần dần chuyển sang viết UI mới bằng Compose thay vì XML
    5. Áp dụng cho app ReFood:
        - Feature list: đăng nhập, xem danh mục, chi tiết sản phẩm, giỏ hàng, đặt hàng, lịch sử đơn; backend có thể dùng Firebase hoặc một REST API đơn giản
        - Tập trung vào kiến trúc sạch, phân lớp rõ, test được; sau này mang đi showcase khi apply job Android
